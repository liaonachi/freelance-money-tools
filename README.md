# Freelance Money Tools

Free calculators for freelancers: hourly rate, invoice late fees, tax set-aside. Built with Next.js (App Router) + Supabase + Vercel — forked from the [SEO Tool Site Starter](https://github.com/liaonachi/seo-tool-site-starter) delivery template.

See `CLAUDE.md` for how to work in this repo and `specs/blueprint.md` / `specs/demo-site.md` for the build spec and status.
